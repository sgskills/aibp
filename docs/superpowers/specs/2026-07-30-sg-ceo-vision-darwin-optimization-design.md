# sg-ceo-vision Darwin 优化设计

## 目标

将 `sg-ceo-vision` 从单场景实测 81.2 分提升到 90 分以上，同时保持其既有的商业机会识别、年度路线图、独立运行边界和离线 HTML 报告契约。

## 不变项

- 不自动调用、推荐或依赖其他 Skill。
- 不扩展到投放代操、采购执行、财税法律结论或外部账号操作。
- 不改变 HTML 模板的视觉设计与 `DESIGNED BY SHIGUANG` 页脚。
- 不引入新依赖，不新增运行时脚本。

## 第一轮改动

1. 在不可逆决策前加入显式 `🔴 STOP / CHECKPOINT`：缺少最大可承受损失、现金上限或退出成本时，禁止给出加码、囤货、签长期合同、清库存等结论；只允许输出补数清单和可逆下一步。
2. 增加“失败恢复表”：资料无法读取、口径冲突、关键资料不足三种场景均明确写出停止项、仍可交付项与恢复条件。
3. 固化证据台账字段：每条关键判断使用“结论｜证据状态｜来源位置｜会改变结论的条件”。
4. 增加集中式“禁止误判清单”：支付 ROI 不等于利润、高点击不等于需求、单表不外推全年、不补造行业阈值、不自动串联其他 Skill。

## 验证

- 静态：frontmatter、引用路径、运行时中立性、SKILL.md 体积与现有仓库校验。
- 实测：机会扫描、资料不足、重大不可逆投入三种场景各做有/无 Skill 对照；至少两位独立评审比较输出。
- 保留条件：新总分必须严格高于 81.2，且达到 90；任一核心边界退化则不保留改动。

## 风险控制

- 仅改 `skills/sg-ceo-vision/SKILL.md` 与其现有评测资料；不重写业务定位。
- 当前工作区有未提交的双 Skill 迁移改动，因此本轮不自动创建 Git commit，以免混入此前范围；通过 diff、校验器和对照实测保留可审计证据。
