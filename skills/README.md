# AIBP Skill 目录

本目录始终采用 `skills/<slug>` 平铺结构。`core`、`commerce`、`tooling` 只是理解与路由标签，不是磁盘分类目录。

| 分轨 | Skill | 用途 | 精确路径 |
| --- | --- | --- | --- |
| `core` | CEO视角 | 商业方向、资源取舍与未来 12 个月路径 | [`sg-ceo-vision`](sg-ceo-vision/) |
| `commerce` | 电商经营结构化拆解 | 跨模块经营问题拆解与验证优先级 | [`sg-mece`](sg-mece/) |
| `commerce` | 天猫推广诊断 | 推广报表审计、诊断与行动优先级 | [`sg-tmads-report`](sg-tmads-report/) |
| `tooling` | SG Skill 优化器 | 既有 Skill 的证据化优化与回归 | [`sg-skill-optimizer`](sg-skill-optimizer/) |

稳定安装包统一从 [AIBP Latest Release](https://github.com/sgskills/aibp/releases/latest) 下载。仓库与安装包采用平台中立的 Agent Skill 结构；具体 Runtime 兼容性仍以实机验证为准。
