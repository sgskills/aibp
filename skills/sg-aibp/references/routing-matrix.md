# AIBP 路由矩阵

路由先看用户要得到的主要结果，再看输入与行业。每次只选择一个首选 Skill；多 Skill 顺序必须有真实依赖。

| 主要结果 | 必要上下文或典型输入 | 首选 Skill | 让位边界 |
| --- | --- | --- | --- |
| 商业方向、资源取舍、未来 12 个月路径 | 多个业务方向、资源限制、战略材料 | `sg-ceo-vision` | 只是查证复杂事实时让位 `sg-research`；电商单点问题让位对应专业 Skill |
| 来源可审计的复杂研究报告或研究任务包 | 复杂问题、多来源、反证、冲突、尽调 | `sg-research` | 只是建立陌生主题认知地图时让位 `sg-blackcat` |
| 陌生主题的来路、同类坐标、圈内语言与认知地图 | 概念、人物、产品、技术、圈层 | `sg-blackcat` | 要求穷尽证据、尽调或正式研究报告时让位 `sg-research` |
| 电商跨模块问题树与第一验证优先级 | 流量、转化、商品、库存等多模块问题 | `sg-mece` | 已明确为评价、榜单、广告报表、标题或产品图时让位对应专业 Skill |
| 电商评价五模块分析与隐藏商业机会 | 用户合法提供的评论文本、CSV、JSON、XLSX | `sg-review` | 不抓取商品链接；市场榜单让位 `sg-toplist` |
| 产品图视觉指纹、身份锚点和防漂移约束 | 用户提供或合法可读的 1–N 张产品图 | `sg-shiwu` | 不负责生图、选品、卖点或 Listing 文案 |
| 天猫商品榜单结构、跨期变化和机会假设 | 单期或多期排名 XLSX、CSV、TSV | `sg-toplist` | 评价让位 `sg-review`；广告报表让位 `sg-tmads-report` |
| 国内货架电商商品标题 | 商品事实、原标题、平台、搜索词或竞品词 | `sg-title` | 公众号/短视频标题、完整 Listing 或市场趋势不适用 |
| 天猫推广报表审计、ROI 与推广毛利情景 | 天猫推广 CSV/XLSX、成本与口径 | `sg-tmads-report` | 不负责跨模块经营总诊断或平台后台代操作 |
| 既有 Skill/Agent 的诊断、优化、测试和打包 | Skill 目录、SKILL.md、触发或回归问题 | `sg-skill-optimizer` | 普通业务对象的“优化”不适用 |

## 常见组合顺序

- 业务方向尚未确定：`sg-research` 补关键证据 → `sg-ceo-vision` 做资源取舍。
- 电商问题尚未定位：`sg-mece` 先拆模块 → 命中评价、榜单、广告、标题或产品图后再进入对应专业 Skill。
- 新产品视觉生成准备：`sg-shiwu` 先固定产品身份；后续生图不属于当前 AIBP 十项专业能力。
- 发现 Skill 本身存在触发或输出问题：先由对应专业 Skill 暂停业务结论，再用 `sg-skill-optimizer` 诊断 Skill；两者不能互相替代。
