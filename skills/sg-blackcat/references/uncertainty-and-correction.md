# 不确定性与纠错

## 类型分开

- **可核验事实**：来源正文直接支持且未越出范围。
- **主流解释**：稳定解释，不冒充正式定义或全体共识。
- **争议观点**：显示持有者、语境和反方。
- **黑猫综合**：从事实推得；说明依据、替代解释和改变条件。
- **未知**：证据或工具不能回答；不填默认值，不猜首创者、日期或出处。

同一段可包含多种类型，但逐句标清。来源只支持它实际覆盖的内容。

## 来源冲突

不要按数量投票或折中平均。依次比较：

1. 定义、词形、分母或样本口径
2. 来源版本、发布日期、事件日期和数据期
3. 方法、测量误差与修订机制
4. 作者、原始文本和数据血缘
5. 学科、社群、地域和使用场景

仍不能消解时并列呈现，说明每个说法在哪个口径下成立，以及什么证据能改变判断。

## 因果与综合

先把主张写成可检查的经验命题：对象/人群、暴露或干预、比较对象、结果、时间范围与适用情境。再判断用户问的是描述、预测还是因果；定义、提出者原话和机制想象都不能替代经验检验。

先后发生、相关、统计显著、机制想象、人物经历或架构特征不能单独证明因果。因果措辞须与实际设计相称：随机对照、可靠准实验或自然实验可加强因果识别；观察研究还要检查混杂、反向因果、选择偏差、测量误差和合理的竞争解释。时间顺序是必要条件之一，机制证据可增强解释但不能单独证明效应。达不到门槛时写成“相关”“与……一致”或“可能解释”，并标明黑猫综合及能改变判断的证据。

不要用 `p < 0.05` 单独证明效应真实、重要或足够大，也不要把“不显著”直接写成“没有效应”。按来源能提供的范围报告效应量、区间/不确定性、样本与设计限制；外推到不同人群、场景或时期必须另给依据。

原始论文、首篇论文或经典实验只能证明其发表内容和历史位置。说明“论文作者主张什么”后，再分开回答后续研究支持、质疑还是未决；若原文已撤稿、更正或方法受到实质争议，核对通知原因和受影响结论，不能把作者主张升级成当前科学共识。

人文、哲学、伦理和规范性概念按文本解释、概念一致性、历史语境、论证前提与反例评价；不因没有实验就贬为不科学，也不把价值选择伪装成经验事实。

## 历史解释与交叉洞察

时间线回答“先后发生了什么”，不能自动回答“为什么”。把早期选择与今天的优势、短板或圈层文化连接时，先区分：

- 当事人或可靠研究明确提出的解释；
- 多项事实共同支持、但仍由黑猫推得的综合；
- 只有时间先后或故事相似性的猜测。

“黑猫综合”至少写出事实支点、可能机制、替代解释和失效条件。历史人物的动机若没有日记、访谈、档案或同期记录，不用后见之明代替证据。一个主题今天成功，不能倒推早期每个选择都正确；一个主题今天衰落，也不能倒推当年的选择不合理。

圈内共识、黑话或经典地位要限定社群、平台与时期。社区高频出现可证明“这里有人这样使用”，不能证明整个领域一致接受，更不能证明经验命题为真。

## 引文断链

交付前核对：

- 正文每个编号/脚注都解析到唯一来源条目。
- 来源条目确实支持相邻主张，而非只支持主题。
- 无正文、失效链接或只有摘要的条目降为线索。
- 不能补证时，删去精确断言、标成未知或改用不依赖该证据的教学例子。

## 纠错流程

1. 明确指出哪一句或哪一层标签有误。
2. 给出更正后的表述和可定位来源。
3. 说明错误影响哪些定义、边界、例子或结论。
4. 保留仍未知或仍有争议的部分，不用新猜测覆盖旧错误。
5. 若用户提供的材料与权威来源冲突，解释冲突而非迎合。

纠错时同步更新受影响主张的来源版本、核验日期、适用域、支持状态、失效条件和影响范围。只更新时间而未重新读取正文，必须保留上次核验状态，不能写成“已重新验证”。

## 离线与部分核验

只交付可确认的定义、边界和明确标注的原创例子。把词源、首创、引语、精确日期、标准版本、当前用法和争议列为待核查；说明恢复条件是获得联网检索和可读正文。不要伪造链接、来源标题、访问时间或“已交叉验证”。

## 合同标识

- `[UNCERTAINTY-TYPES]`：事实、解释、观点、综合和未知分开。
- `[CONFLICT-LINEAGE]`：按口径、版本、方法和血缘处理冲突。
- `[CAUSALITY-GATE]`：证据不足时不用因果措辞。
- `[UNKNOWN-PENDING-CHECK]`：未知与待核查可见。
- `[CORRECTION-PROTOCOL]`：更正内容、影响与剩余未知可审计。
