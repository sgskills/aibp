# 证据与机会筛选规则

## 证据台账

| 类型 | 定义 | 使用限制 |
|---|---|---|
| 事实 | 指定资料中可核验的数据、记录、用户原话或已完成实验 | 记录来源文件和位置，不扩大结论范围 |
| 推断 | 从事实得出的解释或因果判断 | 写明推断链，不当作已证实结论 |
| 待验证 | 缺失后会改变优先级或风险判断的信息 | 写清取数路径或最小实验 |
| 数据矛盾 | 指标口径、时间范围、公式或分母互相冲突 | 停止唯一结论，输出情景分析 |

## 机会审查维度

逐项说明以下维度，不制造没有证据的总分：

1. **商业价值**：可能改变收入、利润、现金流或长期资产的幅度。
2. **证据强度**：需求、可行性和单位经济是否有直接材料支持。
3. **可控性**：结果主要是否由可执行的内部动作影响。
4. **复利性**：是否沉淀客户、品牌、内容、数据、渠道或能力。
5. **学习速度**：多久能得到足以改变决策的有效信号。
6. **最坏损失与可逆性**：失败损失是否可承受，是否能停止或撤回。

## 知识产权与品牌资产检查点

仅当机会或行动涉及商标/品牌名、产品设计与包装、图片/视频/字体/肖像、软件/数据、供应商/员工/外包成果或许可合作时启动；无相关信号时不增加报告负担。

1. 建立台账：`资产｜权利人｜权属或授权证据｜使用范围｜主要风险｜下一步`。使用范围说明已知的渠道、地区、期限和商用边界；未知项标为待验证，不把口头保证当作权属或授权证据。
2. 同时判断该资产能否形成差异化、复利、许可收入或议价能力；没有材料时不编造权利范围或商业价值。
3. 权属或授权缺失、冲突且下一步涉及批量生产、包装印刷、上架、付费分发或长期合作时，局部 STOP：仅暂停受影响动作，继续不受影响的可逆分析。恢复条件是补齐可核验材料、使用范围与争议状态。
4. 不把模型判断当作法律结论；存在重大争议、投诉或禁限风险时，明确建议用户取得合格专业意见。

## 机会分流

| 分类 | 条件 | 必需交付 |
|---|---|---|
| 现在做 | 价值明确、证据足够、风险可控 | 负责人、投入、结果指标、复盘节点 |
| 先测试 | 价值高但关键假设未证实 | 最小实验、投入上限、成功指标、停止条件、复盘时间 |
| 长期建设 | 值得但短期不能证明回报 | 资产或能力里程碑、阶段证据、复盘条件 |
| 主动暂缓 | 价值不足、不可控或证据过弱 | 暂缓理由、重新评估或重启条件 |

## 决策红线

- 无可靠证据时，不承诺具体收益、ROI、销量、行业阈值或平台规则。
- 高投入或不可逆行动必须先确定损失边界；没有边界时优先可逆实验。
- 不用个案数据直接外推到不同人群、渠道、周期或产品。
- 资料不足时宁可说明“尚不能可靠判断”，也不把模型推测写成事实。
