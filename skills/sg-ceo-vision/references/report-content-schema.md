# HTML 决策报告内容规范

## 交付契约

- 输出为单个自包含 HTML 文件，可离线打开。
- 不依赖外部字体、CDN、图片服务、账号或网络请求。
- 使用模板的深海军蓝、冷白纸张和单一钴蓝强调色。
- 页脚右下角保留 `DESIGNED BY SHIGUANG`。

## 页面顺序

1. **报告页首**：资料范围、日期、证据完整度和版本。
2. **CEO 结论**：3 至 5 句话回答应停止、测试、加码什么以及原因。
3. **关键决策栏**：当前重心、最大不确定性、最大风险和下一复盘点。
4. **机会组合**：现在做、先测试、长期建设、主动暂缓及排序理由。
5. **12 个月地图**：0 至 30 天、Q1、Q2 至 Q3、Q4 的目标、里程碑和改道条件。
6. **90 天行动板**：目标、投入、负责人、期限、成功指标和停止条件。
7. **证据台账与红线**：事实、推断、待验证项、来源和不可逆风险。
8. **知识产权与品牌资产**：只在触发检查点时展示权属/授权台账、局部 STOP、恢复条件和长期资产价值；无相关信号时省略。

## 内容纪律

- 关键判断必须带“事实”“推断”或“待验证”标签。
- 任何数字必须来自资料或展示计算方法；未知数字不补值。
- 任何建议都要同时说明验证方式和停止条件。
- 报告没有足够证据时，减少结论而不是增加修辞。
- 知识产权结论必须区分可核验证据与待验证项，不把模型判断写成法律结论。
