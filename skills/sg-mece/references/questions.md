# sg-mece 候选追问题库

本文件是**候选问题池**，不是固定问卷。主 Skill 先判断信息状态，再只选尚未回答、且答案会改变框架选择或第一优先级行动的问题。

提问数量没有硬上限：简单问题可不问；复杂问题可继续追问，直到可以做出可靠判断。优先分批询问，先解决最影响决策的不确定性。

---

## 框架 1：流量拆解

1. 你主要在哪个平台运营？（淘宝/抖音/小红书/拼多多/微信/其他）
2. 流量变化从什么时候开始？是某天突变、持续下滑，还是周期性波动？
3. 变化发生在整体流量还是特定渠道？（自然/付费/搜索/推荐/内容/私域）
4. 最近 30 天做过哪些调整？（价格、主图、详情页、投放、主推款、内容频率、库存、类目属性）
5. 最近两个可比周期的总访客、主要来源绝对值及占比分别是多少？
6. 若问题集中在搜索：核心词的曝光、排名、点击率、转化率哪个先变化？

## 框架 2：转化漏斗

1. 你能看到哪些漏斗数据？请给曝光/访客、点击、加购、下单、付款中的已有项。
2. 用户主要在哪个环节流失？（看了不点、点了不加购、加购不下单、下单不付款、复购低）
3. 客单价、到手价和主要竞品的价格位置是什么？
4. 流量主要来自自然、付费、私域还是达人？不同来源的转化是否不同？
5. 近期是否改变过主图、详情页、价格、优惠、物流或售后承诺？

## 框架 3：选品决策

1. 现在有哪些候选品？每个品解决什么需求？
2. 目标人群是谁？包含典型场景、支付能力和购买动机。
3. 已看到哪些需求和竞争证据？（搜索、竞品、评论痛点、价格带、内容互动、成交）
4. 你的资金、供应链、内容能力、履约能力和合规条件分别怎样？
5. 当前目标是验证需求、快速起量还是长期利润？可承受的试错损失和周期是多少？
6. 若没有市场数据：可否先选 3–5 个候选方向做低成本取数，而不是直接确定品类？

## 框架 4：内容矩阵

1. 你在做什么内容形式和平台？（短视频、图文、直播、长视频等）
2. 已发布多少内容、持续多久、更新频率怎样？
3. “没人看”具体指没曝光、低点击、低完播、低互动，还是互动不转化？
4. 内容的变现路径是什么？（挂车、私域、品牌、合作等）
5. 是否有对标账号或已验证的内容样本？它们的目标人群和表达方式是什么？

## 框架 5：用户分层

1. 当前累计用户、粉丝或会员规模大约多少？
2. 能看到哪些用户数据？（累计消费、购买次数、最近购买、客单价、渠道、标签）
3. 复购率、沉默率或流失率是多少？口径是什么？
4. 现在最想解决拉新、复购、唤醒、裂变中的哪一项？
5. 有 CRM、后台标签、表格或私域触达工具吗？

## 框架 6：利润拆解

1. 毛利率使用什么公式？是否只扣进货，是否已含退款、平台费、物流或广告？
2. 同一自然月的实收营收、订单数、客单价、退款金额分别是多少？
3. 最大三项成本是什么？请给金额或同一分母下的比例。
4. 退货率按订单数还是金额计算？商品能否二次销售？退货损失包含什么？
5. 广告、达人和内容投入按成交额、实收还是单均计算？
6. 数据有矛盾时，先统一口径；未统一前不得给唯一利润结论。

## 框架 7：卖点提炼

1. 产品是什么？核心功能、材质、工艺或参数是什么？
2. 目标用户是谁？其典型场景、痛点和购买顾虑是什么？
3. 用户购买是为解决痛点、获得利益、满足情感，还是建立身份认同？
4. 与直接竞品相比，已被证实的差异是什么？请区分事实与主观感觉。
5. 现有文案、详情页或用户评价如何描述产品？

## 框架 8：工作流拆解

1. 每天或每周最耗时的三项任务是什么？各花多少时间？
2. 哪些任务重复、规则明确、低判断成本，哪些必须人工判断或协作？
3. 现有人员、工具、AI、自动化和数据系统分别有哪些？
4. 目标是省时间、降错误、提升产出，还是释放人力做更高价值工作？
5. 哪个环节出错或延迟的损失最大？

## 通用问题池

当八大框架均不完全匹配时，按目标、现状、差距、历史尝试、资源和约束选择问题：

1. 你希望最终做出什么决定或改善什么指标？
2. 问题从什么时候开始，影响范围多大？
3. 已有数据、证据和口径是什么？
4. 已经尝试过什么，结果如何？
5. 可用资源、时间窗口和不可接受的风险是什么？
