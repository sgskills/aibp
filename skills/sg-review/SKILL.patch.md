# sg-review 0.3.0-rc.1 重构摘要

本轮不是在 `0.2.0-rc.4` 上继续增加门禁，而是回到“天猫链接评价分析师 V1.1”的业务任务重新设计默认体验。

## 核心变化

1. **恢复五模块主线**：完整报告固定为本期总体评价、用户需求、场景、人群、情绪，再以综合结论和 P0/P1/P2 行动收口。
2. **隐藏商业机会必须输出**：只要存在有效评价，完整报告至少一条；支持证据、机会类型、非整改说明、置信度、反证和验证闭环必须可见。
3. **弱证据不等于省略**：单点评价仍形成低置信度探索性假设；只有低信息文本时只能形成评价资产机会，不虚构产品需求。
4. **缺数据也要完成报告**：保留受影响模块，使用 `【数据不足，以下为推断性分析】`，说明已知、未知、推断和补数项。
5. **工程状态退出正文**：不再要求经营者阅读 `FOUND`、哈希、审阅身份和报告阶段等内部状态。
6. **清理过度门禁**：删除独立编码/机会审阅脚本和 CSS 防绕过测试；保留确定性统计，把报告校验缩到 V1.1 结构和关键业务边界。
7. **恢复证据化画像**：允许根据多条购买行为、场景和动机形成推断画像，但精确人口属性仍需明确数据。

## 保留的安全能力

- 数据源只读、隐私脱敏和内部评价编号；
- 评分阈值、评价覆盖率与提及份额分开；
- 无日期不做趋势，无同口径不做 SKU/竞品优劣；
- 无成本效果数据不声称 ROI，无实验不写因果；
- 单商品买后评价不冒充市场空白、市场规模或确定收益。

## 回滚

重构前完整副本保存在维护者的本地备份区；该机器专属路径不进入公开发布说明。
