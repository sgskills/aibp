# 特征提取方法

## 自适应七维检查表

只检查与当前商品和图片有关的维度。维度不适用时省略；相关但看不清时记录“不可判断”，不得为了七栏齐全而补猜。

七维是工程检查表，用于降低漏检和混写风险，不是经统计验证的测量量表，也不代表七项等权或穷尽产品外观。某维是否适用、字段如何拆分，都必须回到本次图片中的可观察证据。

1. **主体形态**：可见轮廓、相对比例、部件数量、层级和连接关系。透视图只描述可见比例；隐藏面与真实长宽高不填。
2. **可见表面与光学呈现**：哑光/亮面、粗细视觉纹理、透光、反射或半透明表现。没有规格佐证时，材质和工艺写“视觉呈现为”或“疑似”；触感不由图片证明。
3. **纹路与图案**：内容、位置、方向、密度、重复节奏和边界。刺绣、压纹、镭射、木纹、皮纹等制造或材料判断只能标为外观推断。
4. **色彩与分区**：相对主色、辅色、明暗、饱和倾向和分布区域。没有色卡、中性光或校色链时，不给精确色值、潘通号或确定的标准色名。
5. **轮廓与局部结构**：倒角、圆润程度、开孔、接缝、按钮、把手和装饰边的位置关系。没有尺度参照时，不写圆角半径或准确尺寸。
6. **标识与文字**：标识的位置、形状、版式与确实可辨的文字。模糊时写“不可辨”，不猜品牌、字体、语言、印刷工艺或真伪。
7. **状态与成像条件**：展开/折叠、开/合、装配状态，以及视角、背景、光影、景深、反射和渲染痕迹。状态与成像条件必须与身份不变量分开。

透明、镜面、强反光和软体产品应跨背景、角度或状态核验：背景透色和环境倒影通常不是本体颜色；软体褶皱和受力形变通常是状态变量，除非多图支持其固定结构。单张图中与高光、亮斑、阴影、曝光渐变或背景透色同位置的局部色区，只能记录为当前成像表象或拍摄伪影；没有跨中性光/角度证据时，不得标为身份不变量或编入固定锚点。

服装与软体物的闭合结构必须看见齿链、纽扣、暗扣等对应局部后才能命名；只有一条门襟或接缝线时，只描述“正面纵向开合/拼接线视觉”，不得升级成“拉链”。平铺或穿着图中的“宽松、修身、直筒”等轮廓同时受尺码、姿势、受力和视角影响，除非有跨状态证据与可靠规格，只能作为当前状态下的视觉轮廓，不能固化为身份锚点。

## 多图交叉验证

在同一实体或变体组内，按字段选择最清楚的图片作为主证据，其他图片用于支持、补充或形成冲突。不要选一张“代表图”覆盖全部字段。

- 多图一致且排除明显拍摄伪影时，可以提高该字段的离散置信等级，但必须保留具体理由；重复角度或同源复制图不算独立证据。
- 不同角度提供互补信息时，分别引用对应 IMG 与局部位置。
- 实拍与渲染不一致时，不默认任何一方更真实；标记冲突并限制锚点。
- 规格与图片表象不一致时，分别记录“用户提供规格/引用资料”和“清晰观察”，不得改写证据类型。

## 固定身份锚点

先按 P0、P1、P2 排序，再编译简洁、自然、工具中立的中文描述：

- 纳入获支持的 `身份不变量`，以及当前变体独有的 `变体特征`。
- P0 是错了就会变成另一商品的辨识特征；P1 是明显影响复刻但不单独决定身份的特征；P2 是可省略或弱影响细节。
- 同款多色先写共享身份锚点，再为每个变体写差异片段；不得把多个颜色合成一个不存在的综合色。
- 排除 `状态变量`、`拍摄伪影`、`未知`、未解决冲突和没有证据的位置。
- 不写具体生图工具语法、参数或效果承诺。身份锚点是下游输入，不是生成结果。

## 场景变量与负面约束

把视角、摆放状态、背景、灯光、阴影、景深、环境倒影和可替换道具列为场景变量。只有确属商品状态且用户要求固定时，才在当前任务的状态片段中保留。

负面约束应针对已发现的漂移风险，例如“不得把透明本体染成背景色”“不得把配件并入主体”“不得互换两个颜色变体”“不得补写不可辨 Logo”。不得写与当前证据无关的通用负面词堆。
