# 意图与版本合同

## 定位与范围

- 主要任务：国内货架电商商品标题的事实化生成、优化与交付前校验。
- 组合定位：当前是独立的 `sg-title` 包，本候选未纳入 AIBP，也不依赖 AIBP 导航、版本或更新检查。
- 发布状态：仅为 GitHub 就绪度候选，不是已发布版。未建仓、未提交、未推送、未公开，未获得这些动作的默认授权。
- 权利状态：保留 frontmatter 中 `SGSkills Internal Use License 1.0`。当前包缺权威许可证全文；在全文由权利人提供前，不声称允许公开再分发。

## 变更和兼容性

- 候选变更限于输入 fail-closed、高风险证据门、Unicode 空白硬要求、偏好隔离、混合路由、平台档案 30 天惰性检查、原标题优先的保留/微调/受限重构、天猫 59–60 旧字节经营硬标准、简单/深度输出和相应回归。
- 现有 `SKILL.md` 入口、`scripts/title_guard.py` 调用方式和冻结 Golden 格式保留。Python 3.12/Windows 已实测；macOS、Linux 和其他 runtime 仍未验证。
- 平台官方数字、空格和符号口径不冒充当期硬规则；天猫 59–60 旧字节明确标为所有者经营标准，不冒充官方事实。平台档案到复核日后只降级，不自动续期，经营标准不随官方档案到期而自动失效。

## 已知事项与停止条件

- 冻结 Golden 中存在标题事实词未全部登记但 expected 为 `allowed=true` 的历史样本。因此，当前实现可阻断空词源、无来源的已申报核心词、幽灵核心词和已枚举高风险短语，但不能在不改冻结 expected 的前提下，将“标题所有普通事实词全覆盖”改成统一强制门。
- 不得用针对冻结 ID、特定标题或文件路径的例外绕过这个冲突。后续如需完整表面覆盖，必须由维护者批准新的输入迁移合同与 Golden 版本，再做可比迁移。
- 发布停止条件：许可证全文缺失、公开分发权利未核验、平台当期硬规则未由后台或官方正文确认时，不声称可直接公开发布或永久合规。
