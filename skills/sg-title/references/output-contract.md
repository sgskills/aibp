# 输出合同

## 简单模式交付（默认）

适用于事实清楚的单商品任务：

1. **处理决定**：保留原标题 / 微调原标题 / 重构标题；原标题已合格时直接写“保留原标题”；
2. **最终标题**：当前证据下最稳妥、已通过可执行硬检查的标题；
3. **精确字节数**：天猫按旧字节口径回显最终值；其他平台只有明确可执行口径时才回显；
4. **备选标题**：默认不提供；用户要求比较，或确有会改变选择的真实取舍时，才提供最多 1 个；
5. **简要依据**：最多 3 个短要点；
6. **必要提醒**：只披露会影响当前选择的规则警告或高价值缺口。

简单模式交付不输出 profile 版本、除上述精确字节数外的逐项长度测量、完整校验 JSON、内部字段、词根矩阵、试错过程、“已运行校验”类过程声明或后续扩展建议。平台未确认只在影响当前选择或上架可用性时披露，不在每次答案末尾例行提醒。为兼容冻结评测，旧称“快速交付（默认）”仅指本模式，不构成第三种模式。

## 深度交付（按需）

用户明确要求深度分析，或任务涉及事实歧义、多来源趋势、规则冲突、图片识别、偏好写入时，提供推荐标题，并按需展开事实台账、关键词矩阵、数据可比性、风险清单和规则证据；默认仍不生成 HTML。深度不等于多给标题：用户未要求比较且没有实质取舍时，只给推荐版；有取舍时可给 1–2 个备选。用户明确要 2 个备选时，有足够安全差异则给 2 个；否则少给并说明，不能用未证实属性凑数。

## 标题候选字段

以下字段供内部校验或用户明确要求的深度结果使用，快速交付不回显：

- `title`；
- `role`：recommended / alternative；
- `core_terms` 及其来源；
- `preserved_phrases`；
- `split_phrases` 与理由；
- `revision_mode`：keep / micro_edit / rebuild；
- `original_title_qualified` 与 `original_order_preserved`；
- `guard_status`：passed / blocked / not_run；
- `platform_rule_status`：hard_checked / advisory_only / unknown；
- `notes`。

被 `title_guard.py` 阻断的候选不展示为可用标题。工具未运行时明确写 `guard_status=not_run`，不要用人工估算冒充精确长度或合规通过。

## 数据少时

交付当前事实支持的简短标题，并说明没有为了补长度加入新属性。若平台数字口径未确认，不能把“未达到旧口径”写成失败；天猫按本 Skill 的 59–60 旧字节经营硬标准执行。若已激活硬最小长度且词源不足，则不输出假合格标题，改列补充项。

## 偏好卡

用户要求跨会话记住但当前无获准存储能力时，附可复制 JSON 偏好卡，并写“当前未永久保存”。提供 profile_id、作用域、来源、确认时间、版本、状态和偏好；不含个人敏感信息。用户已给的标量值原样保留，包括数值/字符串类型和中文平台名；内部校验所需的平台 code 不得替换用户可见卡片中的原值。不添加与已有字段同义重复的偏好字段。
