# 指标与口径

## 总原则

- 所有周期、计划和日期层比率均为 `Σ分子 ÷ Σ分母`，禁止对行级或每日比率取算术平均。
- 0 是有效观测；空值是缺失。分母为 0 时结果为 `不可计算` 并记录原因。
- 只使用输入原始值、明确公式推导值、用户提供的经营参数，或可核验且标注日期/适用范围的官方事实。
- 数据岛之间在归因、类型或互斥性未确认时不得相加。

## 基础汇总

| 指标 | 公式 | 必需字段 |
|---|---|---|
| ROI / 投产比 | 总成交金额 ÷ 花费 | 总成交金额、花费 |
| CPC | 花费 ÷ 点击量 | 花费、点击量 |
| CTR | 点击量 ÷ 展现量 | 点击量、展现量 |
| 订单 CVR | 总成交笔数 ÷ 点击量 | 总成交笔数、点击量 |
| 订单均价 | 总成交金额 ÷ 总成交笔数 | 总成交金额、总成交笔数 |
| 买家 CVR | 成交人数 ÷ 点击量 | 成交人数、点击量 |
| 人均成交金额 | 总成交金额 ÷ 成交人数 | 总成交金额、成交人数 |
| 每点击成交金额 | 总成交金额 ÷ 点击量 | 总成交金额、点击量 |

如果报表存在口径明确的“人均成交金额”，可以引用原值；周期汇总仍优先使用总成交金额 ÷ 总成交人数复算，并标注差异。没有该字段时，才按该公式推导。

## 禁止交叉的指标对

恒等校验应分别成立：

```text
订单 CVR × 订单均价 = 每点击成交金额
买家 CVR × 人均成交金额 = 每点击成交金额
```

不得使用“订单 CVR × 人均成交金额”，也不得使用“买家 CVR × 订单均价”。如果订单数和成交人数差异明显，只描述口径差异，不猜原因。

## 商品毛利口径

本 Skill 的“商品毛利率”仅指：

```text
(成交金额 - 商品成本) ÷ 成交金额
```

它不扣广告费、平台费、物流、人工、税费、达人佣金或其他经营费用。因此以下结果只能叫“推广贡献盈亏”，不得称“净利润”：

```text
推广贡献盈亏
= 总成交金额 × (1 - 退款金额率) × 商品毛利率 - 花费
```

保本 PPC：

```text
保本 PPC
= 总成交金额 ÷ 点击量 × (1 - 退款金额率) × 商品毛利率
```

其中退款率必须是**退款金额率**，不能用退款订单率或退款人数率替代。公式需要商品毛利率、退款金额率和对应基础字段全部存在；任一缺失就不输出数值。

当前规范 JSON 的两项费率是顶层统一参数，必须同时声明 `scope: store-wide` 才参与计算。适用范围缺失或不一致时，保留费率输入和警告，但关闭推广贡献盈亏与保本 PPC。

若一个全店统一毛利率或退款金额率套用多个日期或多个商品：

- 允许计算；
- 只把推广贡献盈亏和保本 PPC 明确标为“情景估算”；ROI、CPC 等基础数据事实不加该标签；
- 不把商品组合变化解释为真实利润变化；
- 可给敏感性分析，但情景值必须来自用户确认，不自行编造上下限。

## 比率输入

- `0.4` 表示 40%。
- 明确的字符串 `40%` 可换算为 0.4。
- 裸数 `40` 或字符串 `"40"` 不自动换算；必须追问“是 40% 还是其他单位”，确认后规范化为 `0.4` 或 `"40%"`。
- 合法范围为 0–1；超出后标为无效，不参与盈亏计算。

## 粒度与不可计算

- 没有关键词列：不能输出关键词名单、关键词 CPC、降价比例或关键词动作。
- 没有商品 ID/名称：不能声称识别到具体商品问题。
- 没有日期：不能输出真实每日趋势；不得按行号伪造日期。
- 没有归因窗口：可以描述报表记录值和同期变化，不能说广告“带来”“新增”多少成交。
- 花费、点击、订单或成交人数为 0：涉及该分母的比率为不可计算，不以 0 替代。
