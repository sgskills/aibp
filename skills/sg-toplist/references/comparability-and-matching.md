# 可比性与商品匹配

## 先建立快照岛

使用以下完整键划分单期快照，任一维度不同都不得直接合并：

`platform × scope × category × ranking_metric × period_start/end × top_n`

平台字段缺失、口径未知或类目含混时单独成岛并降级，不要填入最常见值。若一张“全网”榜内逐行包含天猫/淘宝等平台属性，保留“全网”作为榜单范围，并把行级平台构成作为结构分析；只有显式筛选后才能称“全网榜中的天猫子集”。

## 建立跨期序列

- 跨期只连接除周期外口径相同的岛。记录周期长度、相邻关系、是否重叠、是否有缺口。
- 周期重叠时不得把差异描述为连续变化；周期有缺口时可以做间隔对比，但不能满足“连续周期”的较强趋势条件。
- Top-N 不同时，仅构建 `K=min(N1,N2,...)` 的共同 K 比较切片；所有进入、退出、重合和变化均以 Top-K 重算并显式标注 K。
- 不得把不同平台、范围、类目或排名指标的结果相加后描述为同一市场变化。可以并列展示各岛差异，但结论分别限定。
- 周期排序使用开始/结束日期，不使用文件名顺序。

## ID 匹配规则

1. 将商品 ID 作为不透明字符串精确匹配，保留前导零、大小写和原始值；不要做数值加减。
2. 商品 ID 代表商品链接，不代表规格 SKU。不得从同一 ID 推断规格、包装或价格完全一致。
3. 同一 ID 跨期标题或店铺发生大幅变化时，列出前后标题、店铺、周期和相似度证据，标记“疑似链接重用”。在确认前切断商品级轨迹，不把变化归给同一商品。
4. 标题相同或近似但 ID 不同，只列“可能同款/迁移候选”；不得自动合并。店铺、品牌、价格等也只能增强候选说明，不能覆盖 ID。
5. ID 缺失或同岛重复时，不用标题补配；保留为未匹配记录并解释分母变化。

标题规范化仅用于发现变化/候选，可处理空白、大小写和常见标点；必须保留原文。不得删除型号、数量、规格等可能区分商品的信息后自动匹配。

## 轨迹状态

按相邻可比窗口、共同 K 和可靠 ID 计算：

- `持续在榜`：前后期均在所给 Top-K。
- `新进入窗口`：前期不在 Top-K，本期在 Top-K；只说明相对所给榜单窗口。
- `退出窗口`：前期在 Top-K，本期不在 Top-K；只能写“退出所给 Top-K 窗口”。
- `回榜`：至少有三个可比期，商品更早出现、紧邻前期缺席、本期再次出现。两期数据不能识别回榜。
- `平台新上榜`：仅复述源表平台标记，并单独统计；不得等同于新商品或新进入窗口。

不得把窗口外商品写成下架、销量为零、停止投放或退出市场。当前数据不能区分窗口外排名、缺数、链接变化与真实停止销售。

## 自有商品识别

- 只用用户明确给出的店铺名、商品 ID 或确认清单标记自有商品。允许规范化空白和大小写，但报告匹配方式。
- 店铺名近似、品牌词出现或标题相似只能列候选并要求确认。
- 对每个自有商品优先展示商品 ID、标题、店铺、所在岛、排名/区间轨迹、相邻竞品和数据限制。
- 自有商品疑似链接重用或 ID 重复时沿用相同阻断规则，不因“重点分析”放松匹配。

## 必备可比性说明

每个跨期结论至少附：比较文件/周期、数据岛键、共同 K、匹配依据、前后有效样本数、排除数量及原因。没有这些信息时只输出单期审计或快照。
