# 输出契约

## 交付硬规则（JSON 与 Markdown 共用）

- **身份原值不可改写。** 身份值必须逐字来自结构化结果或源表；店名、品牌名、商品ID不得翻译、扩写、品牌化、大小写改写或无证别名替换。别名或解释只能另列并附证据，不能替换原值。
- **短不等于缺字段。** 压缩不得省略关键口径：每个关键结论保留来源键及其周期、范围、排名口径、Top-N/共同 K/分母；每个行动保留验证指标、周期设置逻辑、停止/回退条件。
- **证据窗口不等于实验周期。** 不能把源表统计周期直接当作测试周期。源表 7 天、30 天或其他跨度只描述输入统计窗口；测试周期须依据榜单更新频率、同长可比窗口、用户目标、历史基线或实验预登记，依据缺失就先确认，不写固定天数。
- **局部形态不得普遍化。** 不得把部分缺失、部分区间或单个字段的能力缺口普遍化为全列事实。仅当结构化计数支持时，才可写“全部为区间”“全列缺失”等全称判断；否则交付精确值、区间或边界值、缺失各自的数量。
- **最终逐值核对。** 最终回答前逐项核对所有店名、商品ID和数字是否可定位到源值；不一致或无法定位时，必须恢复源值、删除或标为不可得。

## 通用开头

先给一段“分析口径”，至少包含：

- 交付模式与选择原因。
- 文件、工作表、周期、类目、范围、平台构成、排名指标、Top-N 和共同 K。
- 数据岛数量及可比/不可比关系。
- 有效行、缺失/重复 ID 或排名、疑似链接重用、污染项和被降级指标。
- 全量与清洗后口径；清洗规则必须显式。

任何数量、比例和变化都附分子/分母或公式。事实引用使用紧凑格式，例如：`[文件｜工作表/周期｜岛键｜Top-K｜商品ID/源行或聚合口径]`。

JSON 顶层必须保留 `delivery_guardrails`，至少包含身份逐字规则、源店名及位置、压缩必留字段、周期设置规则、字段形态计数和最终逐值核对规则。Markdown 在正文前部显著输出“交付硬规则（压缩也不得省略）”，并用同一来源键连接身份原值、事实和行动。

## 极速分析版

严格保持短小：

1. **数据质量结论**：一句话，写清可比性与最大缺口。
2. **事实信号**：最多 3 个。单期只写快照/线索；两期写短期变化信号。
3. **机会假设**：最多 3 个，每个给置信度与替代解释/限制；证据不足时少给，不凑数。
4. **最值得验证的动作**：打品、研发、主推各 1 个。每个保持完整证据链，可用紧凑字段呈现。
5. **最大限制**：只选当前最影响判断的一项，并说明补证方式。

事实与假设分栏或分段，不把建议混入事实。没有自有商品时，把动作写为候选测试，不点名要求某 SKU 加码。

## 深度分析版

按数据条件输出下列结构；某节不可算时保留标题并说明原因，不编值：

1. **数据审计与可比性**：字段、口径、岛、共同 K、匹配风险、区间、平台构成和污染证据。
2. **榜单结构**：头部/窗口构成、店铺/品牌集中、平台分布；仅描述所给榜单。
3. **商品轨迹与更替**：持续在榜、新进入窗口、平台新上榜、回榜、退出窗口、排名上升值和疑似链接重用。
4. **显式属性分析（条件允许）**：店铺、品牌、价格和标题显式提及。缺价格不做价格带；标题词不当需求。
5. **用户商品定位**：按用户确认的 ID/店铺逐品展示；未提供则写“待确认”，不猜。
6. **机会矩阵**：事实、替代解释、假设、置信度、用户匹配与证伪方式。
7. **打品/研发/主推路径**：选择与证据强度相称的最小、可逆行动。
8. **验证与止损**：指标、周期、阈值来源、停止/回退条件及需要转交的专业分析。
9. **不确定性**：最大限制、缺失字段、样本边界、敏感性和不可回答的问题。

## 建议块格式

每条建议保持以下字段，即使为了篇幅合并成一句也不能丢失：

```text
观察事实：
数据位置和口径：
变化模式：
可能解释：
替代解释/限制：
机会假设（置信度）：
行动：
验证指标、周期设置逻辑和停止/回退条件：
```

## 允许与禁止措辞

| 数据条件 | 允许 | 禁止 |
|---|---|---|
| 单期 | 快照、线索、当期榜单构成 | 趋势、增长、持续走强 |
| 两期 | 短期变化信号、进入/退出窗口 | 趋势已形成、下架、衰退 |
| 三期 | 趋势候选 | 确定趋势、长期趋势 |
| 至少四个合格期且双指标同向 | 较强趋势（仍有替代解释） | 原因已证实、必然持续 |
| 标题词 | 标题显式提及、表达变化 | 消费者需求、真实属性、购买动机 |
| 排名 | 序数位置、上升值 | 销量增幅、市场份额、GMV、利润 |

## 表格与格式

- 默认输出 Markdown/文字；仅当比较关系明显时使用表格，叙事与限制用段落。
- 不默认或锁定 HTML。用户明确要求 HTML 时，仍遵守同一内容契约，并转义所有源单元格文本。
- 表格不得隐藏分母、共同 K、估算标签或缺失值；缺失写“不可得/不可算”，不写 0。
- 区间中点一律标“中点估算”；清洗结果一律与全量结果并列。
- 结尾不要承诺伪精确效果，不附固定 1–12 个月计划，也不加入与分析无关的提示词保密条款。
