# 排名指标与趋势措辞

## 排名是序数

- 定义 `排名上升值 = 前期排名 - 本期排名`。结果为正表示名次上升，为负表示下降，0 表示不变。
- 名次差只能表示顺序移动，不能线性解释销量差、流量增幅、份额、GMV 或竞争力差距。第 1 与第 2 的差距不等于第 100 与第 101。
- 排名本身不能证明上升/下降原因。营销、价格、评价、库存、季节等只能作为待验证解释，除非另有直接证据。
- 汇总名次变化优先报告计数、中位数、四分位数和分布；即使报告均值，也注明序数限制。

## 榜单结构指标

在每个可比岛或共同 K 内重算，并显示分子/分母：

- 有效商品数、有效唯一 ID 数、平台构成、店铺/品牌构成（字段可靠时）。
- 共同商品数、窗口重合率、留存数、新进入窗口数、退出窗口数、回榜数。
- Top-10/20 等子窗口只在所有周期都覆盖该 K 时比较，并明确 K。
- `平台新上榜`使用源字段单列，不与新进入窗口相减或互相替代。
- 店铺或品牌集中度只能称“所给榜单中的商品条目构成”，不得称市场销量份额。

若使用重合率，写清公式。例如 `共同 ID 数 / 两期 ID 并集数`（Jaccard）或 `共同 ID 数 / 前期有效 ID 数`（留存率），不要混用同一个名称。

## 区间指标

对前期区间 `A=[A_low,A_high]`、本期区间 `B=[B_low,B_high]`：

- 变化区间 `B-A=[B_low-A_high, B_high-A_low]`。
- 下界大于 0 才可称“确定增加”；上界小于 0 才可称“确定减少”；包含 0 时写“方向不确定/区间重叠”。
- 中点 `(low+high)/2` 只能称“中点估算”，不得伪装实测值；报告基于中点的排序时同时给原区间。
- 百分比变化仅在基期下界严格大于 0 且单位一致时给出范围；分母含 0 或缺失时不计算。
- 区间重叠不等于完全没有变化，只表示现有精度不足以判定方向。

## 标题显式属性

- 从标题抽取的材质、风格、人群、场景、规格、功能或关键词统一写为“标题显式提及”。
- 词频、标题新增/删除或共同商品标题变化只反映商家标题表达，不代表消费者需求、商品真实属性或销量驱动因素。
- 同一商品标题跨期变化可以作为运营动作线索；不得据此断言改词造成排名变化。
- 分词、同义词归并和停用词规则必须可复现，并保留原始标题与命中词。
- 若源表另有“商品关键词”，把变化单列为“来源商品关键词字段变化”；不要与标题抽词混合，也不要视为消费者搜索需求。

## 趋势等级

严格使用下列等级，不得升级措辞：

- **1 期：快照/线索。** 只能描述当期结构、异常和标题显式提及。
- **2 期：短期变化信号。** 描述前后差异，不称趋势。
- **3 期：趋势候选。** 说明方向是否连续、是否受单个周期驱动。
- **至少 4 期：较强趋势的必要但非充分条件。** 必须同时满足周期连续、口径可比、互不重叠，且至少两个观测指标在同一业务方向上提供一致证据；仍需写替代解释。

“两个观测指标”必须是分别计算、语义清楚的指标，例如多个商品的窗口进入/退出结构与可用买家区间方向。排名不能单独充当因果证据，标题词频也不能作为需求指标补足条件。

## 污染与敏感性

- 先用明确规则标出错类商品、福利/差价/专拍链接等疑似污染，并列商品 ID、标题、店铺、排名和命中规则。
- 始终保留全量口径结果；另给“按已披露规则清洗后”的结果。不得覆盖原结果或静默删除。
- 比较关键结论在全量与清洗后是否同向、幅度是否稳定、样本是否过小。结论翻转时把机会降为低置信度或不输出。
- 清洗规则只能基于显式证据，不凭主观判断删除不喜欢的竞品。

## 指标禁区

- 无价格字段：不分价格带，不推价格弹性。
- 无支付金额：不计算或推断 GMV。
- 无成本、退款、履约、平台费用等：不判断利润。
- 只有 Top-N：不外推完整市场规模、销量份额或市场增长率。
- 区间访客/买家：不伪精确计算转化率；条件满足时只给可追溯区间并注明局限。
